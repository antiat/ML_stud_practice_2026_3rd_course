# Прогнозирование уровня стресса человека с помощью методов машинного обучения

## Описание проекта

Данный проект выполнен в рамках учебной практики по направлению подготовки «Фундаментальная информатика и информационные технологии».

Цель проекта — разработка модели машинного обучения для прогнозирования уровня стресса человека на основе характеристик образа жизни.

В работе используются методы классического машинного обучения, а также проводится анализ данных, визуализация признаков и сравнение качества различных алгоритмов классификации.

---

## Используемые технологии

- Python
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- Google Colab

---

## Используемый датасет

В проекте используется датасет, содержащий информацию о:
- возрасте;
- уровне тревожности;
- качестве жизни;
- уровне шума;
- использовании социальных сетей;
- уровне стресса.

---

## Этапы работы

1. Загрузка и анализ данных
2. Предварительная обработка данных
3. Удаление пропусков
4. Кодирование категориальных признаков
5. Масштабирование данных
6. Обучение моделей машинного обучения
7. Оценка качества моделей
8. Визуализация результатов
9. Анализ важности признаков

---

## Используемые алгоритмы

В рамках проекта были обучены следующие модели:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

---

## Метрики качества

Для оценки качества моделей использовались:
- Accuracy
- Precision
- Recall
- F1-score

---

## Результаты

Наилучший результат показала модель Random Forest.

Также было установлено, что на уровень стресса наиболее сильно влияют:
- продолжительность сна;
- качество жизни;
- рабочая нагрузка.
