## Описание проекта

Проект посвящён автоматической классификации уровня психоэмоционального стресса у студентов на основе комплекса психологических, физиологических и социальных показателей. Решается задача **многоклассовой классификации** (3 класса: низкий / средний / высокий уровень стресса) с применением алгоритмов машинного обучения.

---

## Цель

Разработать и сравнить модели машинного обучения для предсказания уровня стресса студентов, выявить наиболее значимые факторы и оценить практическую применимость решения для систем психологического мониторинга в университетах.

## Этапы работы

1. **Загрузка и первичный осмотр** — `df.head()`, `df.info()`, `df.describe()`
2. **Анализ пропусков** — `df.isnull().sum()`, визуализация, удаление (`dropna`)
3. **Кодирование** — `LabelEncoder` для категориальных признаков
4. **Разделение** — `train_test_split` (80% train / 20% test, `random_state=42`)
5. **Масштабирование** — `StandardScaler` (fit на train, transform на test)
6. **EDA** — гистограммы, корреляционная матрица, boxplot, pairplot
7. **Обучение 4 моделей** — LogReg, DecisionTree, RandomForest, KNN
8. **Оценка** — accuracy, classification report, confusion matrix
9. **Кросс-валидация** — `cross_val_score`, cv=5
10. **Важность признаков** — `feature_importances_` Random Forest

## Метрики и результаты

Для сравнения использовалась метрика **Accuracy** на тестовой выборке (20%).  
Для лучшей модели дополнительно рассчитывались **Precision, Recall, F1-score** по каждому классу (`classification_report`) и строилась **матрица ошибок** (`confusion_matrix`).

> **Лучшая модель: Random Forest**  
> Подтверждено 5-кратной кросс-валидацией (`cross_val_score`, cv=5).
